# Emotion-to-Image Generation using Generative AI

A Generative AI project that converts human emotions into visually expressive images using state-of-the-art AI models. The system takes an emotion as input and generates an image that reflects the corresponding emotional state, demonstrating the capabilities of modern diffusion-based image generation.

---

## Overview

Emotion-to-Image Generation is an AI-powered application that bridges human emotions and visual creativity. By leveraging Generative AI, the project transforms emotional inputs such as *Happy, Sad, Angry, Fear, Surprise,* and *Neutral* into unique AI-generated images.

This project showcases the integration of Natural Language Processing (NLP) concepts with diffusion-based image generation models to create meaningful and visually appealing outputs.

---

## Features

-  Emotion-based image generation
-  Powered by Generative AI
-  High-quality AI-generated images
-  Easy-to-use notebook implementation
-  Supports multiple emotion categories
-  Customizable prompts for image generation
-  Compatible with Google Colab and Jupyter Notebook

##  Usage

1. Open the notebook in **Jupyter Notebook** or **Google Colab**.
2. Install the required libraries.
3. Load the Generative AI model.
4. Provide an emotion as input.
5. Run the notebook cells.
6. View and save the generated image.
